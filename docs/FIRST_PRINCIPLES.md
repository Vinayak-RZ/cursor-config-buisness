# First-principles thinking

Skill: **`first-principles-thinking`**

Reason from bedrock instead of "how companies like us do it." Distilled from Farnam Street, James Clear, and operator-oriented first-principles writing — packaged so agents in this repo apply a pass, not a TED talk.

## What it is

| Pass | Meaning |
|------|---------|
| **Surface** | Name the conventional answer and the analogy |
| **Question** | Assumptions, why believed, what if false (Socratic / Five Whys) |
| **Bedrock** | `[FUNDAMENTAL]` vs `[STILL ASSUMPTION]`; hard vs soft constraints |
| **Rebuild** | Derive from fundamentals only; function over form |
| **Implications** | What changes, cost of being wrong, smallest test |

## When to use

- "If we started from zero, how would we design this?"
- Pricing, GTM, product, or cost copied from incumbents
- Industry logic might be the bug
- User says first principles, physics-style reasoning, or "challenge our assumptions" *and* wants a rebuild (not only a list)

## vs other skills

| Need | Skill |
|------|-------|
| Rebuild from fundamentals | `first-principles-thinking` |
| Inventory risks | `identify-assumptions-new` |
| Attack a written plan | `strategy-red-team` |
| Design how the enterprise works | `business-model` |
| Fill Lean Canvas | `lean-canvas` |

## Prompts

```text
Use first-principles-thinking on our pricing. We copied $49/seat because that's what others charge.

Run a deep first-principles pass on whether we need a sales team. Outcome: first value in the buyer's week.

Challenge the assumption that we must be a marketplace. Rebuild Who/What/How/Value if we're not.
```
